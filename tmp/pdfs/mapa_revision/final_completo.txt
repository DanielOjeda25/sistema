CU-01 Crear proyecto
Especificación funcional alineada al comportamiento actual


                                                                                                                                         Elemento                Definición actual

                                                                                                                                         Actor principal         Jefe o PM autenticado.

                                                                                                                                                                 Registra un proyecto y lo vincula con un cliente y un
                                                                                                                                         Descripción
                                                                                                                                                                 usuario responsable.

                                                                                                                                                                 Existen el cliente y el usuario seleccionado; el actor
                                                                                                                                         Precondiciones
                                                                                                                                                                 posee rol Jefe o PM.

                                                                 CU-01 Crear proyecto                                                                            Se crea una fila en proyectos, se registra la auditoría y se
                                                                                                                                         Postcondiciones
                                                                                                                                                                 muestra “Proyecto creado correctamente.”

                                                                                                                                                                 1. Abre Proyectos. 2. Pulsa “Nuevo proyecto”. 3.
                                                                                                                                                                 Completa nombre, descripción, fechas, estado, cliente y
                                                                                                                                         Flujo principal
                                                                                                                                                                 responsable. 4. Pulsa “Guardar proyecto”. 5. El sistema
           Jefe / PM                                                                                                                                             valida. 6. Persiste y vuelve al listado.

                                                                                                                                                                 Si faltan datos obligatorios o las referencias no existen,
                                                                                                                                         Alternativa 5a
                                                                                                                                                                 vuelve al formulario con errores y no persiste.

                                                                                                                                                                 Si fecha_fin_estimada es anterior a fecha_inicio, rechaza
                                                                                                                                         Alternativa 5b
                                                                                                                                                                 el alta.

                                                                                                                                                                 Cliente, Programador y PO no disponen de la ruta de
                                                                                                                                         Restricción de acceso
                                                                                                                                                                 creación.

CU-02 Gestionar proyecto - Consulta
Listado, filtros, detalle y aislamiento del Cliente



                           Elemento                               Definición actual

                           Actor principal                        Jefe, PM, PO, Programador o Cliente autenticado.

                           Descripción                            Consulta el listado y el detalle de proyectos visibles para el usuario.

                           Precondiciones                         Sesión iniciada. Para el Cliente, la cuenta debe estar vinculada a una empresa mediante cliente_id.

                                                                  Abre Proyectos, aplica búsqueda por nombre/descripción y filtros por estado, cliente, PM y fechas; el sistema pagina de a
                           Flujo listado interno
                                                                  15.

                           Flujo detalle                          Pulsa Ver; el sistema muestra estado, cliente, PM, fechas, tareas y avance. Desde “Ver detalle completo” accede a la ficha.

                           Flujo Cliente                          El sistema restringe por cliente_id y presenta proyectos propios, hitos, sprints, novedades visibles e informes aprobados.

                           Alternativa                            Proyecto ajeno solicitado por URL: aborta con 403. Filtros sin coincidencias: muestra el estado vacío.

                           Postcondición                          No modifica la base de datos.

CU-02 Gestionar proyecto - Edición
Actualización controlada desde el modal del listado o la ficha



                           Elemento                               Definición actual

                           Actor principal                        Jefe o PM autenticado.

                           Precondiciones                         El proyecto existe y el actor posee permiso de edición.

                                                                  1. Abre Proyectos. 2. Pulsa Editar. 3. El modal recibe la URL y los valores actuales. 4. Modifica campos. 5. Pulsa Guardar
                           Flujo principal
                                                                  cambios. 6. El sistema valida y ejecuta update(). 7. Redirige con “Proyecto actualizado correctamente.”

                           Reglas                                 Las mismas de creación: nombre obligatorio, fechas válidas, estado permitido y referencias existentes.

                           Alternativa                            Si hay errores, no actualiza y vuelve al formulario con mensajes. Una fecha final anterior al inicio es inválida.

                           Postcondición                          Los atributos quedan actualizados; Laravel Auditing conserva la trazabilidad del cambio.

CU-02 Gestionar proyecto - Eliminación
Baja restringida al rol Jefe con confirmación previa



                           Elemento                               Definición actual

                           Actor principal                        Jefe autenticado.

                           Precondiciones                         El proyecto existe y el actor tiene rol Jefe.

                                                                  1. Abre Proyectos. 2. Pulsa Eliminar. 3. El sistema muestra una confirmación. 4. Confirma “Sí, eliminar”. 5. Envía DELETE
                           Flujo principal
                                                                  /proyectos/{id}. 6. destroy() elimina y redirige con mensaje de éxito.

                           Alternativa                            Cancelar o cerrar el diálogo no envía la solicitud y no modifica datos.

                           Seguridad                              PM, PO, Programador y Cliente no tienen la ruta DELETE; un intento directo devuelve 403.

                                                                  La base define ON DELETE CASCADE en varias relaciones dependientes. La baja es irreversible desde la interfaz y debe
                           Impacto
                                                                  usarse con criterio.

                           Postcondición                          La fila deja de existir y el listado se actualiza.

                                                     2. crearProyecto(datos, cliente, responsable)




                                                     confirmación “Proyecto creado correctamente”




listarProyectos() y seleccionarNuevoProyecto() son consultas → sin contrato. crearProyecto() crea estado del dominio → se contrata.


 Operación                            crearProyecto(nombre : String, descripcion : String, fechaInicio : Date, fechaFinEstimada : Date?, estado :
                                      EstadoProyecto, cliente : Cliente, responsable : User)

 Referencia                           Caso de Uso CU-01 «Crear proyecto»

 Tipo                                 Sistema (Cruz Negra)

 Responsabilidades                    Registrar un nuevo proyecto, asignarlo a un Cliente existente y establecer el usuario responsable de su gestión.

 Excepciones                          nombre vacío · fecha de inicio inválida · fecha fin anterior a fecha inicio · estado no permitido · Cliente inexistente ·
                                      User inexistente · actor sin rol Jefe o PM.



 PRECONDICIONES

     • El actor está autenticado y posee rol Jefe o PM.
     • El Cliente recibido existe y está registrado en el Sistema.
     • El User responsable recibido existe y está registrado en el Sistema.
     • La fecha de inicio es válida y la fecha final estimada, si se informa, es igual o posterior.
     • El estado pertenece a {pendiente, en_progreso, completado, cancelado}.
